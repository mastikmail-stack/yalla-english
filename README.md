# יאללה אינגליש

אפליקציה ללימוד אנגלית מעברית. זהו המשך של האפליקציה המקורית שנבנתה עם Claude, עם תיקונים ובדיקות משותפים באותו מאגר.

כתובת האפליקציה הקבועה: https://mastikmail-stack.github.io/yalla-english/

המאגר: https://github.com/mastikmail-stack/yalla-english

## עבודה על אותה גרסה

קוראים את `HANDOFF.md`, מעדכנים מהענף `main`, מבצעים שינויים ובדיקות ודוחפים לאותו מאגר. GitHub Actions מפרסם לאותה כתובת רק אחרי שהבדיקות מצליחות. אין צורך ליצור artifact או קישור חדש.

```sh
node review/checks.cjs
node review/audio-checks.cjs
node review/worker-checks.cjs
node review/build-site.cjs
```

להפעלה מקומית: `python -m http.server 8766`, ואז `http://localhost:8766`.

## בדיקת איכות

בפרופיל מופיעים מספר הגרסה, בדיקת עדכון וקישור למסך בדיקת שמע. המסך כולל את כל האותיות, המילים והמשפטים, עם אפשרות לסמן בעיות ולייצא דו״ח. פריט שלא נבדק אינו מסומן אוטומטית כתקין.

הבדיקות האוטומטיות בודקות נכונות נתונים והתנהגות תוכנה. הן אינן מחליפות האזנה אנושית, בדיקה בטלפון וביקורת של מורה לאנגלית. פרטי מקורות השמע ורישיונותיהם מופיעים באפליקציה ובמניפסטים שבתיקיית `audio`.

ההתקדמות נשמרת מקומית בדפדפן. קובצי גיבוי, הסרטון שנשלח לצורך אבחון ותוצאות בדיקה אישיות אינם נכללים בפרסום.
